# Siri — My PC AI Agent

Native Android + Windows/macOS/Linux companion. The Android app provides Bengali/English voice input, speech replies, safe phone actions, and an authenticated PC connection. General AI answers are generated by a local Ollama model on the PC; the Android app sends requests only to the configured PC Agent.

## Android features

- Bengali/English voice input through Android's system speech-recognition activity.
- Text-to-speech replies; Siri prefers an installed female-sounding voice for the selected language when available.
- Safe phone actions and explicit PC targeting with PC: or phone targeting with PHONE:.
- Optional authenticated PC connection and a PC Test button.
- Chart screenshot OCR through the PC companion; OCR reads visible labels only and is not visual chart understanding.
- GitHub Actions builds and uploads a debug APK.

## PC companion setup

Requirements: Python 3.10 or newer and a local Ollama installation with the qwen2.5:3b model available.

1. Start Ollama on the PC and ensure ollama list shows qwen2.5:3b.
2. Open a terminal in the repository folder and run python pc_agent/server.py.
3. On first run, the server creates a random authentication token and prints it in the terminal. Keep it private.
4. Find the PC's private LAN IPv4 address (Windows: ipconfig; macOS/Linux: network settings).
5. Connect the phone and PC to the same trusted Wi-Fi network. In Siri Settings, enter http://PC-LAN-IP:8765 and the token printed by the PC.
6. Tap PC Test.

The companion uses a local Ollama model for general questions, writing, translation, explanations, planning, and safe command interpretation. PC actions are restricted to the existing allow-listed tools. It never executes arbitrary shell commands or code from the phone. File deletion, purchases, message sending, and security changes are not performed by the AI fallback.

## Network and privacy safety

- Use the PC server only on a trusted private LAN.
- Do not expose port 8765 to the public internet or configure router port-forwarding.
- HTTP on a local LAN is not encrypted; for remote access, use a properly configured VPN rather than public port forwarding.
- The local AI model runs on the PC. The Android app sends its request to the configured PC Agent.

## Binary signal, live collector, and screenshot OCR

The PC companion exposes authenticated, signal-only endpoints:

- POST /api/collector/quotex — accepts normalized candles/ticks from the local collector.
- POST /api/binary/signal — returns CALL, PUT, or NO TRADE; expiry is selected by a rule-based market-regime heuristic.
- POST /api/screenshot/analyze — extracts visible text from an image using optional local OCR dependencies.
- POST /api/binary/analyze — combines optional screenshot OCR with fresh cached collector candles/ticks.

Install Pillow and pytesseract, plus the Tesseract OCR executable, to enable screenshot OCR. OCR does not interpret candle shapes or guarantee trading outcomes. No signal is guaranteed, and the endpoint never places trades. Do not send account credentials, cookies, session tokens, or personal information in screenshots.
